从社区采集 meme：连接浏览器
  1. 给浏览器装扩展 Violentmonkey（在 Firefox 附加组件或 Chrome 应用商店里搜 Violentmonkey）。
  2. 安装采集 meme 脚本，在弹出的页面点「确认安装」。
  3. 在贴吧、小红书、豆瓣或任何网页的右下角点「采集 meme」，勾选要的图采集进来，一分钟内就能在这里搜到。

脚本只在你点按钮时采集你正在看的这一页，不自动翻页、不在后台抓取。采集来的图放在图库的 inbox 文件夹里，并记下来自哪个帖子。
