# P0 results (2026-09-25)

Three pre-build experiments from the design doc (§7). Everything ran on one RTX 5090 with
`torch 2.11.0+cu128`, `transformers 4.57.6`, `sentence-transformers 5.7.0`, `rapidocr_onnxruntime 1.4.4`.
Models: RapidOCR, `OFA-Sys/chinese-clip-vit-large-patch14-336px`, `BAAI/bge-m3`, `Qwen/Qwen2.5-VL-7B-Instruct`.
Only aggregate numbers are recorded here; the E1 images and queries are the maintainer's private data.

## E1 — retrieval on a personal meme collection

Data: 109 personal meme images (all contain text), 25 queries written by the owner with a labeling page.
15 queries are *quote-like* (≥ 50 % of their character bigrams appear in the target's OCR text), 10 are *descriptive*.

| Route | R@1 | R@5 | MRR |
|---|---|---|---|
| OCR text → BGE-M3 | 1.00 | 1.00 | 1.00 |
| Chinese-CLIP (image) | 0.88 | 0.92 | 0.91 |
| VLM description → BGE-M3 | 1.00 | 1.00 | 1.00 |
| RRF(OCR, CLIP) | 0.96 | 1.00 | 0.97 |
| RRF(OCR, CLIP, VLM) | 0.96 | 1.00 | 0.98 |

Descriptive subset only (n = 10): OCR 1.00, VLM 1.00, CLIP 0.80 (R@5).
Two VLM prompts were compared (chat-sticker fields vs topic/punchline fields): identical scores.

- Threshold hybrid R@5 ≥ 0.70: **pass**.
- VLM gain over OCR: **0 points** (< 15) → by the spec's rule, P1 ships without VLM.
- **Ceiling effect:** 109 text-heavy images are too few to separate the routes. This does not show VLM is useless;
  it shows OCR + a multilingual text embedding is enough for a small, text-heavy personal collection.
  VLM's value (memes without text, larger libraries, vaguer queries) is unmeasured.

## E2 — cross-lingual text and base-image similarity (L1)

Data: 20 ImgFlip575K templates; per template 3 English captions. Positive pair = caption vs a Chinese
transcreation written by Qwen2.5-VL (text mode); negative pairs = two different captions on the same template.

| Measure | AUC |
|---|---|
| Text: BGE-M3 cosine, translation vs same-template-different-joke | **1.00** (pos mean 0.76, neg mean 0.45) |
| Base image: Chinese-CLIP on the full image | 0.85 |
| Base image: Chinese-CLIP after masking OCR text boxes | **1.00** |

- Threshold text AUC ≥ 0.90: **pass**.
- Masking text before comparing base images clearly helps (0.85 → 1.00).
- Limitation: positives are machine transcreations (fairly literal; a few garbled), English templates only,
  20 positives / 40 negatives. Real human 译制 will be harder.

## E3 — snowclone pattern detection (L2)

Data: 10 well-known snowclones (6 Chinese, 4 English) × 5 variants + 10 distractors sharing words but not the
pattern; 1,770 sentence pairs. Hand-written dataset. Balanced accuracy on "same pattern?":

| Method | Exact pattern match | Embedding, threshold 0.85 | Embedding, held-out threshold |
|---|---|---|---|
| LLM rewrites sentence to a slotted pattern (zero-shot) | 0.59 | 0.66 | 0.85 |
| Same, few-shot prompt | 0.51 | 0.57 | 0.90 |
| **Raw sentence, no LLM** | 0.50 | 0.55 | **0.93** |

"Held-out threshold": chosen on half of the groups, scored on the other half, both ways averaged.

- Threshold ≥ 0.85: the spec's method (LLM canonicalization + fixed threshold) **fails**; raw-sentence
  embeddings with a calibrated threshold **pass (0.93)**.
- From one sentence, Qwen2.5-VL-7B cannot tell skeleton from slot: it slots fixed words, leaves variants
  unslotted, and slots distractors. Few-shot mostly makes it echo the input.
- Limitation: 60 hand-written sentences, one 7B model.

## Decisions for P1 (proposed)

1. **Retrieval:** OCR + BGE-M3 dense search, fused with Chinese-CLIP via RRF. VLM descriptions become an
   optional backend, off by default — this also keeps the zero-cost CPU tier fully featured for text memes.
   Re-measure VLM on a larger or text-free set before promoting it.
2. **L1 matching:** BGE-M3 on OCR text for cross-language pairs; mask text boxes before comparing base images.
3. **L2 detection:** embed raw sentences, calibrate the threshold on labelled groups; no per-sentence LLM rewrite.
   Extracting the slotted pattern (needed for template generation) should come from aligning several known
   variants of the same pattern, not from guessing on one sentence. *Needs the maintainer's decision.*

## Bugs found on the way

- `transformers 4.57.6`: `ChineseCLIPModel.get_text_features` reads `pooler_output`, but the model builds its
  text tower with `add_pooling_layer=False` → `None` → crash. We compute the projected CLS hidden state instead.
- ImgFlip575K's `popular_100_memes.csv` is Windows-1252, not UTF-8.
